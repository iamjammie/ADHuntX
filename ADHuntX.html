03 — COLLECT

Gather from a live domain (read-only)

A browser can't query LDAP directly, so a small read-only PowerShell collector gathers the data. It performs LDAP search operations and config inspection only — no writes, no exploitation, no secrets.

  1. Download the collector below and copy ADHuntX-Collect.ps1 to a domain-joined Windows machine (a normal domain user is usually enough).
  2. Open PowerShell in that folder (Windows PowerShell 5.1 or PowerShell 7).
  3. Run it: powershell -ExecutionPolicy Bypass -File .\ADHuntX-Collect.ps1 -Output adhuntx-data.json
  4. It shows progress, records any gaps as data-quality warnings, and writes adhuntx-data.json.
  5. Bring the JSON back and import it above (step 02 — drop it on the zone).

What this is
About ADHuntX

          

          

            
ADHuntX — Active Directory Security Intelligence & Attack Path Analyzer. Portable, offline, client-side.

            
A defensive, read-only tool for authorized audits, threat hunting, and training. It performs
               evidence-based misconfiguration analysis, attack-path discovery, and reporting — entirely in your browser.
               It is an assessment platform, not an exploitation tool: no credential dumping, password attacks,
               exploitation, or object modification.

            

              35 assessment rulesAttack-path graph
              Risk scoringRemediation
              HTML · PDF · JSON · CSVNo dependencies
            

            
A browser cannot speak LDAP; live data is gathered by the read-only PowerShell collector and
               analysed here offline. Findings indicate potential exposure and require human validation. Use only on
               directories you are explicitly authorized to assess.
